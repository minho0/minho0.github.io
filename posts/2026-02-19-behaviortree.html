Traversability → Costmap on Jetson (Latency Notes)

Date: 2026-02-19

Summary

This post summarizes a real-time pipeline that runs on embedded GPUs (Jetson), performing on-device traversability inference and generating costmaps/occupancy grids for navigation.

Pipeline

  • RGB-D input → preprocessing
  • TensorRT inference → traversability logits
  • Point projection + filtering
  • 2D costmap / occupancy generation
  • ROS 2 publish (Nav2 integration)

Notes

  • Profile end-to-end latency (camera → publish)
  • Separate GPU inference time vs CPU post-processing
  • Prefer fixed-size buffers to reduce allocations
