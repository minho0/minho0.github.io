SELECTED PROJECTS

RoboCup@Home Service Robot System Integration

Team Leader

Integrated HRI, perception, navigation, and manipulation on the Rainbow Robotics RB-Y1 using ROS 2 and a hierarchical Behavior Tree. Natural-language commands were decomposed using onboard Qwen3-VL and a cloud LLM, while execution results were checked against preconditions, success conditions, and failure reasons. Recovery logic handled re-search, retry, and alternative actions, contributing to a 4th-place finish in RoboCup@Home 2026 OPL.

News Article · Team Description Paper

Aircraft Inspection Robot SLAM Evaluation Framework

Developed a SLAM evaluation framework for GNSS-denied aircraft inspection environments. The framework combines map consistency against an aircraft design model, segment-wise scan-to-map error analysis, and external-camera robot monitoring to identify when and where localization errors accumulate. To test the inspection environment under controlled conditions, I also built an aircraft hangar environment in Isaac Sim and set up a data-acquisition pipeline for collecting simulation data.

Off-road Traversability Costmap Framework

Converted pixel-wise traversability predictions from synchronized RGB-D and odometry data into a robot-centric 2D costmap for the ROS 2 navigation stack. Reorganized the pipeline into ROS 2 nodes and optimized the PyTorch model through ONNX and TensorRT for Jetson AGX Orin, reducing inference latency from about 570 ms to 100 ms and the full costmap pipeline to about 150 ms.

Automated Crane System for Container Handling

Integrated YOLOv10-based container detection, a Rainbow Robotics RB3 730 ES 6-DoF robot arm, and a custom gripper for automated container alignment and grasping. Camera-to-robot coordinate transformation enabled precise alignment between the manipulator and target containers. The system achieved 98% mAP@50, 96% recall, and a 93.5% grasp success rate across 200 trials.
